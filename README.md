# Day_24-Mail-merge-Project
This project automates the process of generating personalised letters using Python.

## How the code works:
The code reads from a .txt file that has a list of names and inserts each name into a template letter (starting_letter.txt), replacing the placeholder [name] with an actual name from the invited_names.txt file. A new customized letter is then created for each person and saved as a separate file.

## What I Learned:
- File handling in Python
- Working with loops (iterating through lists of names to automate tasks)
- Sting manipulation e.g .strip(), .replace()
- How repetitive real-word tasks can be automated with code
- Organizing input and output folders
